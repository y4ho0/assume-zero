# 安全与隐私模型

[English](../SECURITY_MODEL.md) | [中文文档索引](README.md)

## 边界

AssumeZero 使用当前用户权限，在工作区副本中执行用户提供的命令。副本用于防止命令通过普通相对路径直接写入源工作区。它不是沙箱、容器、虚拟机、权限边界，也不是执行不受信任代码的安全方式。

被测命令或准备命令可以主动访问当前用户可访问的网络、主目录、凭据、服务、设备或任意绝对路径。AssumeZero 本身在检查期间不会主动发起网络请求，也不会发送遥测。

## 源码保护

- 被测命令的工作目录始终是新副本。
- 基线、场景、恢复和最小化执行不会复用已修改副本。
- 普通文件按字节复制，绝不会使用可写硬链接。
- 默认排除 `.git` 和以前的 `.assumezero` 证据。
- 除非显式允许，否则拒绝外部符号链接且不读取其目标。
- 在报告持久化前比较源文件指纹和 Git 状态证据。
- `.assumezero` 是有意生成的工具元数据，不计入源文件内容完整性声明。

命令仍然可以故意写入工作目录之外。不要测试不受信任的项目或命令。

## 进程执行

参数直接传给进程 API。`--shell` 必须显式启用，并会警告系统 Shell 将解析脚本。每个进程都有单命令超时和有界输出捕获。发生中断或超时时，AssumeZero 会尝试终止直接子进程并清理临时目录，但无法保证跨平台完整终止全部后代进程。

## 环境值

环境值只在进程内存中用于执行、恢复和精确值脱敏。报告结构包含名称，不包含值。敏感名称包括 token、secret、password、API/access/private-key、authentication 和 credential 等模式。

任何输出摘要写入之前，脱敏会替换：

- 敏感名称的继承环境变量精确值；
- Bearer Token；
- GitHub Token 形态；
- AWS Access Key ID；
- JWT 形态；
- 私钥头；
- 常见数据库连接字符串；
- 主目录、项目目录和场景临时路径。

脱敏不可避免地存在误报和漏报风险。被测命令如果转换或拆分秘密，可能绕过精确匹配。请使用测试凭据，并在分享证据前自行检查。
