# 路线图

[English](../ROADMAP.md) | [中文文档索引](README.md)

以下是候选方向，不是承诺：

1. 保持证据语义、受预算约束的两两场景约简，因为场景交互可能暴露单一变化看不到的假设。
2. 更强的跨平台后代进程终止，同时兼顾可移植性和避免 unsafe 代码。
3. 具有明确隐私模型的可选文件访问证据，用于缩小 `EMPTY_HOME` 发现范围，而不读取无关主目录内容。
4. 能力探测式 Copy-on-Write 加速，并为大型工作区提供完整性回退测试。
5. 更多确定性 Oracle，包括可选文件 SHA-256 检查和规范化结构化输出。

任何路线图项目都不会改变安全边界：AssumeZero 仍是可信有限命令的测试工具，而不是不受信任代码沙箱。
